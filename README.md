# portfolio-dashboard

## Overview
Saas fullstack application built with modern technologies.

## Technology Stack
- **Frontend**: nextjs
- **Backend**: fastapi
- **Database**: postgres
- **Authentication**: auth0
- **Deployment**: vercel

## Features
- admin_dashboard
- api_access
- authentication
- authorization
- multi_tenancy
- subscription_billing
- usage_tracking
- user_management

## Compliance
- NONE

## Quick Start

1. Install dependencies:
   ```bash
   make setup
   ```

2. Start development environment:
   ```bash
   make dev
   ```

3. Run tests:
   ```bash
   make test
   ```
