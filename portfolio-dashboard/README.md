# portfolio-dashboard

## Overview
Enterprise fullstack application built with modern technologies.

## Technology Stack
- **Frontend**: nextjs
- **Backend**: fastapi
- **Database**: postgres
- **Authentication**: N/A
- **Deployment**: aws

## Features
- api_gateway
- audit_logging
- compliance_reporting
- data_governance
- enterprise_auth
- reporting
- role_based_access
- sso_integration

## Compliance
- NONE

## Quick Start

1. Install dependencies:
   ```bash
   make setup
   ```

2. Start development environment:
   ```bash
   make dev
   ```

3. Run tests:
   ```bash
   make test
   ```
