# client01saas

## Overview
Real_Estate_Saas fullstack application built with modern technologies.

## Technology Stack
- **Frontend**: nextjs
- **Backend**: fastapi
- **Database**: postgres
- **Authentication**: jwt
- **Deployment**: docker

## Features
- analytics_dashboard
- audit_logging
- maintenance_tracking
- multi_tenant_management
- notifications
- property_inventory
- rls
- tenant_portal

## Compliance
- NONE

## Quick Start

1. Install dependencies:
   ```bash
   make setup
   ```

2. Start development environment:
   ```bash
   make dev
   ```

3. Run tests:
   ```bash
   make test
   ```
